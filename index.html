Lab 03: CSS Structure and Properties

Objective

  • Use inline, embedded, and external CSS.
  • Use CSS selectors, pseudo-class selectors, and priority.
  • Practice commonly used CSS rules.
  • Use HTML/CSS layout design principles.
  • Use responsive design and media queries.

Current Lab Learning Outcomes (LLO)

By completion of the lab, students should be able to:

  1. Use HTML5 markup tags for structuring web pages.
  2. Identify compatibility issues between well-known browsers.
  3. Use HTML5 with appropriate CSS properties and elements for styling, formatting, and enhancing web pages.
  4. Construct and validate web pages using HTML5 and CSS3.

Lab Requirements

Web browser, browser developer tools, text editor, and HTML and CSS references.

Lab Assessment

1. Image preview

2. CSS selector answers
